SystemVersion, Home button

Flux TV v1.0.113

Home button: Off: Home still opens the built-in home screen. To change it, open Settings → Home screen on the TV.

If the TV's Accessibility switch for Flux turns itself off: first press Unlock the Home button in Flux's Settings → Home screen. If it still turns off, from a computer with ADB connected to the TV run:
adb shell appops set com.fluxtv.app ACCESS_RESTRICTED_SETTINGS allow
then turn the switch on again. Or switch it on directly:
adb shell settings put secure enabled_accessibility_services com.fluxtv.app/com.fluxtv.app.HomeButtonService
adb shell settings put secure accessibility_enabled 1
